# 📊 Sales Insights Hub

Plataforma web para análise de dados de vendas com dashboards interativos, indicadores de desempenho e geração de insights para apoiar a tomada de decisões.

## 🚀 Tecnologias

- React
- TypeScript
- Python
- Pandas
- Supabase
- Plotly
- Git

## ✨ Funcionalidades

- Upload de arquivos CSV/XLSX
- Dashboard interativo
- KPIs de vendas
- Ranking de vendedores
- Análise por período
- Curva ABC
- Análise por forma de pagamento
